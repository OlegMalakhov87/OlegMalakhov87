## Основной проект

### Social Network

Полнофункциональная социальная сеть, разработанная с нуля на React и Node.js.

Проект включает ленту публикаций, комментарии, реакции, личные сообщения, музыку, видео, загрузку медиафайлов и систему пользовательских настроек.

🔗 **[Открыть репозиторий проекта](https://github.com/OlegMalakhov87/social-network)**

### Ключевые возможности 

* Публикации с текстом, изображениями и видео
* Комментарии и лайки с полиморфными связями
* Оптимистичные обновления интерфейса
* Личные сообщения через WebSocket
* Загрузка и обработка медиафайлов
* Генерация превью и thumbnail для видео
* Infinite scroll и пагинация
* Приватность публикаций и контроль доступа
* Светлая и тёмная темы
* Собственная дизайн-система
* Очистка неиспользуемых медиафайлов
* Разделение frontend-логики по FSD
